# CLAUDE.md

Тип проекта: веб-сайт

Основные правила работы со мной (конституция), знания по типам проектов и заметки
по прошлым проектам лежат в отдельном репозитории `nebelph/claude`.

В начале сессии:
1. Подключи репозиторий `nebelph/claude` к сессии через `add_repo` с доступом на запись (`access: push`) — иначе в конце сессии не получится запушить заметку.
2. Прочитай его `CLAUDE.md` из ветки `main` и следуй ему. При противоречии: по общим правилам работы главнее он, по деталям этого проекта — раздел «Об этом проекте» ниже.
3. Прочитай `types/website.md` и заметки по похожим проектам в `projects/`.

В конце сессии создай или обнови заметку `projects/personal-site.md` в `nebelph/claude`
по правилам раздела «Память между сессиями».

Если подключить `nebelph/claude` не получилось — скажи об этом сразу.

## Об этом проекте
Личный сайт-визитка Артёма: https://nebelph.github.io. Одна страница: фото, имя, подпись,
кнопки GitHub / Telegram / Email, переключатель EN/RU. Подробности — в заметке
`projects/personal-site.md` и в `ARCHITECTURE.md`.

- Стек: чистые HTML + CSS + JS без фреймворков и сборки.
- Публикация: GitHub Pages из ветки `main`, папка `/`. Любой merge в `main` сразу публикует сайт.
- Запуск локально: `python -m http.server 8000` → http://localhost:8000.
- После правки CSS или JS увеличь номер версии `?v=N` в ссылках в `index.html`, иначе браузеры до 10 минут показывают старый файл из кеша.
- Служебные файлы (`CLAUDE.md`, `README.md`, `ARCHITECTURE.md`, `assets/src/`) исключены из публикации в `_config.yml`. Новый служебный файл добавляй туда же. Не возвращай `.nojekyll`: с ним Jekyll не запускается, и `exclude` перестаёт работать.
- Фон `assets/background.jpg` выгружен из `assets/src/background.svg` в разрешении 2880×1620; меняешь фон — правь SVG и выгружай заново.
