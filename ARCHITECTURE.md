# Архитектура сайта-визитки

Персональный сайт **Артёма Рудакова**: одна страница, минималистичный дизайн,
два языка (EN / RU), фото и кнопки со ссылками на соцсети.

Публичный адрес: **https://nebelph.github.io**

---

## 1. Ключевые решения

| Вопрос | Решение | Почему |
|---|---|---|
| Тип сайта | Статический (готовые файлы, без сервера) | Для визитки бэкенд не нужен. Статический сайт быстрый, бесплатный и надёжный |
| Технологии | HTML + CSS + немного JavaScript | Без фреймворков и сборщиков: одной странице они не нужны |
| Языки | Английский и русский на одной странице, переключаются кнопкой | Текста мало, поэтому словарь в JS проще, чем две копии страницы |
| Иконки | Встроенные SVG (GitHub, Telegram, Email) | Внешние библиотеки и лишние запросы не нужны, цвет задаётся из CSS |
| Хостинг | GitHub Pages | Бесплатно, репозиторий уже на GitHub, публикация по `git push` |
| Акцентный цвет | Серый | Строгий минимализм |

## 2. Структура проекта

```
nebelph.github.io/
├── index.html          # единственная страница: разметка и SVG-иконки
├── css/
│   └── style.css       # все стили: палитра, фон, раскладка
├── js/
│   ├── i18n.js         # словарь EN/RU и переключение языка
│   └── copy-email.js   # копирование email в буфер обмена + уведомление
├── assets/
│   ├── avatar.jpg      # фото (квадрат ~400×400, до ~150 КБ)
│   ├── background.jpg  # фон: тёмные абстрактные волны (2880×1620, ~200 КБ)
│   ├── favicon.svg     # иконка во вкладке браузера
│   └── src/
│       └── background.svg  # векторный исходник фона
├── _config.yml         # настройки Jekyll: exclude служебных файлов из публикации
├── CLAUDE.md           # указатель для Claude на nebelph/claude (не публикуется)
├── ARCHITECTURE.md     # этот документ
└── README.md           # краткое описание и как запустить локально
```

Роли файлов (аналогия с C++):
- `index.html` задаёт *структуру*: какие элементы есть на странице (как объявления).
- `style.css` задаёт *представление*: как элементы выглядят.
- `i18n.js` задаёт *поведение*: подставляет текст на нужном языке.

## 4. Двуязычность (i18n)

**Механизм:**
1. У каждого переводимого элемента в HTML есть атрибут-ключ, например `data-i18n="name"`.
2. В `i18n.js` лежит словарь:
   - `en`: `name → "Artyom Rudakov"`, …
   - `ru`: `name → "Артём Рудаков"`, …
   - подпись кнопки `Email` не переводится
   - подпись `vibe coder` не переводится и в словарь не входит
3. При загрузке страницы язык выбирается так:
   1. сохранённый выбор пользователя (`localStorage`), если он есть;
   2. иначе язык браузера (`navigator.language` начинается с `ru` → русский);
   3. иначе английский.
4. Кнопка `EN | RU` меняет текст, атрибут `<html lang="…">` и `document.title`,
   а также запоминает выбор.

**Без JavaScript** страница показывает английский текст, записанный прямо
в HTML. Сайт остаётся рабочим.

## 5. Дизайн-система

**Фон:** изображение `assets/background.jpg` (тёмные абстрактные серые волны),
растянутое на весь экран (`background-size: cover`, неподвижно при прокрутке).
Фон нарисован в векторе (`assets/src/background.svg`) и отрендерен в JPEG 2880×1620.
Чтобы изменить фон, правь SVG и заново экспортируй JPEG.
Поверх него лежит полупрозрачное чёрное затемнение 60%: яркость фона 40% от исходной, чтобы он не отвлекал от содержимого.

**Читаемость на фоне:**
- у всего текста тёмная обводка (`text-shadow`, токен `--text-outline`);
- у кнопок полупрозрачная тёмная подложка `rgba(0,0,0,.45)` с размытием фона под ней;
- вокруг фото мягкое светлое свечение (`box-shadow`).
Пока картинка грузится, виден цвет `--bg`. Тема одна (тёмная) при любых настройках системы.

**Палитра** (переменные CSS в `:root`):

| Токен | Цвет | Назначение |
|---|---|---|
| `--bg` | `#0d0d0d` | запасной цвет фона |
| `--text` | `#f2f2f2` | основной текст |
| `--muted` | `#b8b8b8` | подпись, подвал |
| `--accent` | `#8c8c8c` | рамки кнопок, иконки |
| `--accent-hover` | `#ffffff` | кнопка при наведении |
- **Шрифт:** системный (`system-ui, -apple-system, "Segoe UI", Roboto, sans-serif`).
  Грузить его не нужно, кириллица поддерживается.
- **Кнопки:** контурные (1px серая рамка, скругление ~8px), внутри иконка 20px и подпись.
  При наведении рамка и текст становятся белыми, с плавным переходом ~150ms.
- **Иконки:** SVG с `fill="currentColor"`, поэтому наследуют цвет текста кнопки.
- **Фото:** круглое (`border-radius: 50%`), `object-fit: cover`, лёгкая серая рамка.

**Адаптивность и доступность:**
- ширина контента ограничена (~600px), по бокам отступы не меньше 16px;
- у ссылок видимый фокус (`:focus-visible`) для навигации с клавиатуры;
- у фото есть `alt`, у кнопок текстовые подписи, контраст текста достаточный.

**Копирование email** (`js/copy-email.js`):
1. Клик по кнопке Email отменяет переход по `mailto:` и копирует адрес из `data-email`.
2. Основной способ: `navigator.clipboard.writeText` (работает на HTTPS и `localhost`).
   Запасной: скрытое поле `<textarea>` и `document.execCommand("copy")`.
3. Внизу экрана на 2,5 секунды появляется уведомление на текущем языке:
   «Email copied to clipboard» / «Email скопирован в буфер обмена».
   Если скопировать не удалось, в уведомлении показывается сам адрес.
4. Уведомление имеет `role="status"`, поэтому экранные дикторы его озвучивают.

## 7. Публикация на GitHub Pages

Чтобы сайт открывался по адресу `https://nebelph.github.io`, репозиторий должен
называться **строго** `nebelph.github.io`.

Шаги:
1. ✅ **Переименовать репозиторий:** GitHub → `nebelph/mysite` → *Settings* →
   *General* → *Repository name* → `nebelph.github.io`.
   Старые ссылки и `git remote` продолжат работать через редирект, но remote лучше обновить:
   `git remote set-url origin https://github.com/nebelph/nebelph.github.io.git`.
2. **Влить код в `main`:** GitHub Pages публикует выбранную ветку.
3. **Включить Pages:** *Settings* → *Pages* → *Source: Deploy from a branch* →
   ветка `main`, папка `/ (root)` → *Save*.
4. Через 1–2 минуты сайт доступен по адресу `https://nebelph.github.io`.
5. Дальше любое изменение публикуется так: `git push` в `main`, и сайт обновляется сам.

Репозиторий уже публичный. На бесплатном тарифе это обязательное условие для Pages.

---

**Кеш браузера.** GitHub Pages разрешает браузеру кешировать файлы до 10 минут.
Поэтому в `index.html` ссылки на CSS и JS содержат номер версии
(`css/style.css?v=8`). После изменения CSS или JS номер нужно увеличить,
чтобы браузер сразу скачал новый файл.

## 8. Локальная проверка

```bash
cd MySite
python -m http.server 8000
# открыть http://localhost:8000 в браузере
```

Что проверить:
- переключатель языков и то, что выбор сохраняется после перезагрузки;
- фон на экранах разной ширины и высоты;
- ширину экрана телефона (DevTools → режим устройства);
- что каждая кнопка ведёт по правильной ссылке.
