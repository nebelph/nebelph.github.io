# nebelph.github.io

Персональный сайт-визитка Артёма Рудакова: https://nebelph.github.io

Статическая страница (HTML + CSS + немного JS), EN/RU, градиентный серый фон.
Архитектура описана в [ARCHITECTURE.md](ARCHITECTURE.md).

## Запуск локально

```bash
python -m http.server 8000
# открыть http://localhost:8000
```

## Публикация

GitHub Pages публикует ветку `main` (папка `/`). Любой push в `main` обновляет сайт.
